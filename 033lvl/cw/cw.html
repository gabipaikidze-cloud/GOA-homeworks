4. Fixed ღილაკი

ეს არის ვებგვერდის პირველი ტექსტი. აქ შეგვიძლია დავწეროთ საინტერესო ინფორმაცია სხვადასხვა თემაზე.

ვებგვერდი შედგება სათაურებისგან, ტექსტებისგან, სურათებისა და სხვა ელემენტებისგან. HTML გამოიყენება გვერდის სტრუქტურის შესაქმნელად, ხოლო CSS მის გასაფორმებლად.

CSS-ის დახმარებით შეგვიძლია შევცვალოთ ფერები, ზომები, დაშორებები და ელემენტების მდებარეობა.

Position თვისება გვეხმარება ელემენტების განლაგებაში. არსებობს static, relative, absolute და fixed მნიშვნელობები.

Static არის ჩვეულებრივი განლაგება. Relative ელემენტს საწყისი ადგილიდან გადაადგილების საშუალებას აძლევს.

Absolute ელემენტი პოზიციონირდება მის უახლოეს პოზიციონირებულ მშობელ კონტეინერთან მიმართებით.

Fixed ელემენტი ეკრანზე ერთსა და იმავე ადგილას რჩება, მაშინაც კი, როდესაც გვერდს ვსქროლავთ.

ეს არის დამატებითი ტექსტი გვერდის გასაგრძელებლად. შეგიძლია ჩამოსქროლო და დააკვირდე ღილაკის მდებარეობას.

ვებდიზაინი ძალიან საინტერესო სფეროა. მისი შესწავლით შეგვიძლია საკუთარი ვებსაიტების შექმნა.

კიდევ ერთი ტექსტი, რათა გვერდი უფრო გრძელი იყოს. ჩამოსქროლე ქვემოთ და ნახავ, რომ ღილაკი ისევ ეკრანის ქვედა მარჯვენა კუთხეში დარჩება.
