4. Fixed Contact Button

მოგესალმებით ჩემს ვებგვერდზე. აქ შეგიძლიათ გაეცნოთ საინტერესო ინფორმაციას.

HTML არის პროგრამირების ენის მსგავსი მარკირების ენა, რომელიც ვებგვერდის სტრუქტურის შესაქმნელად გამოიყენება.

CSS გამოიყენება ვებგვერდის გასაფორმებლად. მისი დახმარებით ვცვლით ფერებს, ზომებს, დაშორებებსა და განლაგებას.

ვებდიზაინი ძალიან საინტერესო სფეროა. შეგვიძლია შევქმნათ სხვადასხვა ტიპის ვებგვერდები.

CSS-ში არსებობს position თვისება, რომელიც ელემენტების მდებარეობის მართვაში გვეხმარება.

Static არის ჩვეულებრივი განლაგება, Relative გადაადგილებს ელემენტს საწყისი ადგილიდან.

Absolute ელემენტს ათავსებს პოზიციონირებული მშობელი ელემენტის მიმართ.

Fixed ელემენტი ეკრანზე ერთსა და იმავე ადგილას რჩება, მიუხედავად სქროლვისა.

ეს არის დამატებითი ტექსტი, რათა გვერდის ჩამოსქროლვა შევძლოთ.

ვებგვერდის შექმნა HTML-ისა და CSS-ის დახმარებით შეგვიძლია.
